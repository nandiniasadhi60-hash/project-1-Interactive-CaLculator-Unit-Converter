
# 🧮 Interactive Calculator & Unit Converter

## 📌 Project Description

The Interactive Calculator & Unit Converter is a web-based application developed using HTML, CSS, and JavaScript.

This application allows users to perform basic mathematical calculations and convert different units such as length, weight, temperature, time, data, and speed.

It provides a simple, attractive, responsive, and user-friendly interface.

---

## 🎯 Project Objectives

- Perform basic mathematical calculations.
- Convert different measurement units.
- Provide fast and accurate results.
- Create a responsive web application.
- Improve frontend development skills.

---

## ✨ Features

### 🧮 Interactive Calculator

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal calculations
- Clear (AC) button
- Delete (DEL) button
- Keyboard support

### 📏 Unit Converter

The application supports six conversion categories:

1. Length
   - Meter
   - Kilometer
   - Centimeter
   - Millimeter
   - Mile
   - Foot
   - Inch

2. Weight
   - Kilogram
   - Gram
   - Milligram
   - Pound
   - Ounce
   - Tonne

3. Temperature
   - Celsius
   - Fahrenheit
   - Kelvin

4. Time
   - Second
   - Minute
   - Hour
   - Day
   - Week

5. Data
   - Byte
   - KB
   - MB
   - GB
   - TB

6. Speed
   - Meter/Second
   - Kilometer/Hour
   - Mile/Hour
   - Foot/Second

## ⚙️ Installation and Setup

### Step 1: Download the Project

Download or clone the project repository.

### Step 2: Open in VS Code

Open the project folder using Visual Studio Code.

### Step 3: Check Files

Make sure all four files are available:

- index.html
- style.css
- script.js
- README.md

### Step 4: Run the Application

Open index.html in your web browser.

You can also use the Live Server extension in VS Code.
